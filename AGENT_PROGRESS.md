## Decisions made

**Stack**
- **Astro 7 + TypeScript.** Repo was empty; static generation, near-zero JS,
  and a first-class image pipeline all fit a photography site.
- **No UI framework, no CSS framework.** The whole site ships hand-written CSS
  and ~4 kB of vanilla JS (nav, reveal, lightbox).

**Photographs live in `src/assets/`, not `public/`** — deliberate deviation
from the folder sketch in the brief. Astro can only generate AVIF/WebP
derivatives, srcset and intrinsic dimensions for images under `src/`. Files in
`public/` are copied untouched, which would have cost the performance
requirements in §34. The demo/real split the brief asked for is preserved as
sibling folders: `src/assets/demo/**` vs `src/assets/portfolio/**`.

**Demo images are generated, not downloaded.** The environment's network
policy blocks every stock-photo host (403 via the proxy on picsum, unsplash,
pexels), and the brief rules out hot-linking. `npm run demo:generate` produces
them locally, so there is no licence question at all. Full reasoning in
`docs/demo-assets.md`.

**Design**
- White background, `#101010` text, two greys. Colour only from photographs.
- No CSS filters over photographs — never auto-grayscale a colour photo.
- Inter (variable) + Instrument Serif for display. Both self-hosted; Google
  Fonts would add a third-party request and is unreachable at build time here.
- **Justified gallery rows**: flex-basis proportional to aspect ratio, so a row
  shares one height while every photo keeps its native ratio. No cropping.
- Every third landscape photo becomes a full-width anchor, for rhythm.
- One photo per row below 48rem — two portraits side by side at 360px are
  unusable.
- Dark lightbox; the rest of the site stays light.
- Mobile nav is a full white sheet, not a dropdown.

**Content**
- Czech throughout, including URL slugs (`/o-mne/`, `/cenik/`, `/portfolio/svatby/`).
- **No invented facts.** No fake biography, no fake prices, no fake phone
  number. Placeholders are visible and flagged in the UI where a visitor would
  otherwise be misled (draft notice on About, "Cena na vyžádání" on Pricing,
  placeholder contacts hidden from the footer).
- Contact page has **no form**, on purpose: a form on a static site means
  choosing a third-party provider and therefore where visitors' messages land.
  That is the client's decision. `mailto:` until they make it.

**Deployment**
- GitHub Pages, project site. `site` and `base` come from `SITE` / `BASE_PATH`
  env vars so moving to a custom domain is a one-line workflow change.
- All internal links go through `path()` in `src/lib/paths.ts`, so nothing
  breaks under a base path.
